# Capture client

Operate mode. Preserve Material 3 and the native React Native Paper controls on
Android and Linux. Sync and Settings are the two top-level destinations.

Sync shows local queue, transfer progress and server confirmation separately.
Transcription jobs show the server's real state, stage, progress and error. A failed
Notion backup cannot turn a confirmed primary save into a failed upload.

Use a single column with wrapping action groups, system type, theme-aware contrast
and 48dp touch targets. Errors stay visible and selectable; controls name the action.
No marketing copy. Avoid repeating completed-state explanations. Device controls
must expose a visible submit action, validate the firmware's actual range and
report readback failures.

Server audio is authoritative after the API confirms `saved: true` for the matching
upload identity. Explicit local removal is available only for confirmed source
frames. Never infer confirmation from HTTP success or the Notion backup field.
